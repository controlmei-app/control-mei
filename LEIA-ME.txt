CONTROL MEI 5.0 — Venda integrada

Abra index.html para teste local ou publique TODOS os arquivos na raiz do repositório GitHub Pages.

NOVO: Estoque > Vender, ou Estoque > Registrar venda com baixa automática. Uma venda cria receita bruta e saída de estoque com IDs vinculados. Estorne a movimentação no Estoque para desfazer ambos. O backup JSON mantém vínculos entre registros.

Atenção: não há login, nuvem, pagamentos ou validação fiscal completa. Dados armazenados no navegador; faça backups. Não use dados reais sem testes e política de privacidade.
